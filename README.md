# FCRK Scouting

**Приложение для академии Футбольного Клуба "Рубин Казань".**
- мониторинг последних обновлений в общей, облачной базе данных игроков по периодам во времени
- добавление/удаление игроков и изменение в специальном редакторе информации по этим игрокам
- редактирование карьерных этапов движения игрока по футбольной вертикали, результатов актуального тестирования игрока и его трансферных деталей
- поиск игроков с помощью простых и составных фильтров и таких категорий, как "Избранное" или "Добавленное мной"
- работа с планом просмотра: ближайшие соревнования, отправка задач тренерам по рекомендованным игрокам во внутреннюю систему клуба

**Платформа:** UIKit

**Архитектура:** MVVM

**Работа с данными:** CoreData + CloudKit

**Работа с сетью:** URLSession + Combine

**Многопоточность:** GCD

**Авторизация:** Authentication Services (Sign in with Apple)

**Статус:** публикация была снята с App Store по внешнеполитическим причинам, используется как портфолио-проект
